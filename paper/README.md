## 修改与重建

直接编辑 `paper.md`，然后运行：

```bash
bash build.sh
```

脚本会自动安装 pandoc（`pypandoc-binary`）与 matplotlib，重新生成图表、样式模板与 .docx。
仅改文字时也可单独执行最后一步的 pandoc 命令（见 `build.sh`）。

## 论文要点

- **感知-控制解耦框架**：ResNet-18 从固定相机 RGB 回归物体平面位姿，替代真机不可得的特权状态。
- **课程式四阶段门控奖励**：将抓取-放置分解为抓取/搬运/下降/释放四阶段，配合防推挤、防早开、
  防硬性跌落、防滞留等失败抑制惩罚，缓解长时序稀疏奖励的信用分配难题。
- **Sim-to-Real**：结构化域随机化（摩擦/光照/相机/杂物等 6 类、4 级）+ 感知误差注入，
  并给出系统化鲁棒性评估协议。
