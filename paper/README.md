**机械臂的强化学习算法**。论文内容与本仓库 `src/isaac_so_arm101/` 的真实实现及作者提供的
《项目流程详解》《奖励函数详解》文档保持一致，按**"阶段性成果 + 诚实分析"**定位撰写。

## 与真实项目/文档的一致性（本次据实修订要点）

1. **奖励函数权重已对齐当前代码**：reaching `+1.0`、lifting `+5.0`、stage2 `+10.0`、stage3
   各项 `+12/-8/+14/+14/+2`、stage4 各项 `+12/-10/+11/+16/+2`，外加全程 `action_rate −0.1`、
   `joint_vel −0.1`（共 15 分阶段项 + 2 平滑惩罚），并新增**抬起锁存器 latch（防"不抬直接推"作弊）**。
2. **视觉以 ResNet-18 为主线 + 诚实对比颜色掩码**：如实写出"ResNet-18 数据集相关系数约 0.92、
   但因训练-部署域差直接部署仅约 6%"，而颜色掩码方案部署约 32%、对光照近乎免疫。
3. **实验数据据实**（来自文档 funnel_v9）：抓取 GT≈35.6%、视觉≈32%，端到端放置≈8%–11%。
4. **据实剖析"抓住不放"局部最优**（持续抬起收入流 + 空中目标），并给出改进方向。
5. 观测≈28 维、动作=5 连续关节 + 1 二值夹爪、50 Hz/250 步/4096 并行环境等细节均按代码修正。
6. 修复了引言中"引用变成页脚脚注"的问题（`^[...]^` 被 pandoc 误判为行内脚注，已转义方括号）。
